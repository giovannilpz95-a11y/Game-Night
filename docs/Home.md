# Game Night

A Roblox hub where friends join one party and play many board, card and party games without leaving. Empty seats are filled by bots, so even one player can start any game.

- [[Roadmap]]: the four build steps and where we are
- [[Architecture]]: how parties, tables, turns and bots work
- [[Adding a game]]: the checklist for every new game
- [[Game list]]: every game we plan to make, with working titles
- [[Naming and trademarks]]: why some games get our own names

> This folder is an Obsidian vault. In Obsidian, choose **Open folder as vault** and pick the `docs` folder of the repo.
