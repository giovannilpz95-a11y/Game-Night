# Naming and trademarks

Back to [[Home]].

Names like Uno, Monopoly, Scrabble, Clue, Catan, Risk, Pictionary, Battleship, Jenga and Trivial Pursuit are trademarks. Their owners (Hasbro, Mattel and others) do file takedowns against Roblox games that use them. Since Game Night is meant to be published and grow, we make **our own games with the same kind of gameplay**, and give them our own names, art and rule tweaks.

Classic public-domain games keep their names: Chess, Checkers, Tic-Tac-Toe, Dominoes, Backgammon, Mancala, Go, and card games like Crazy Eights or Hearts.

Rules of thumb:
- Never use the trademarked name, logo, box art, board layout or character names.
- Gameplay mechanics are fine to share (matching colors, trading properties, drawing and guessing).
- Pick a name that describes the game, like "Color Clash" or "Sketch & Guess".
